🛜 **A curated and maintained collection of 500+ ready-to-use captive portals built for the Marauder firmware — and compatible with any firmware that uses HTML-based portal structures.**

**Evil Portal Website**
https://rianhanft.github.io/Rians_Evil_Portals_For_Marauder/

This repo features new types of captive portals where the UI doesn't appear old and/or outdated, while also adding more advanced menu navigation/multiple ways a "victim" can login. (NOTE: not all portals have the same UI/advanced features.)

## Verified Format For Captive Portals

| Requirement              | Status  |
|--------------------------|---------|
| `action="/get"`          | ✅ All  |
| `name="email"`           | ✅ All  |
| `name="password"`        | ✅ All  |
| No `method=` attribute   | ✅ All  |
| No external dependencies | ✅ All  |
| JavaScript-free forms    | ✅ All  |

📦 **Installation:**

  Download the captive portal .html file(s) you want to use.

  Paste the HTML file(s) to the root directory of your Marauder's (or similar firmware's) storage/SD card.

  Launch the device and select the .html captive portal file you want to use.
____________________________________________________________________________________________________________________________________________________________________________________________________
🚨 **Important:** 

  **The HTML files must be located in the root directory of the Marauder's storage. If they are placed inside another folder, the portals will not show up on your device's menu screen.**
